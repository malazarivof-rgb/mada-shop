# MADA SHOP

Marketplace Madagascar — interface V1.

## Lancer le projet

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000

## Pages incluses

- Accueil
- Boutique / catalogue
- Détail produit
- Panier
- Dashboard vendeur
